# Educational SystemC/TLM timer and real-CPU mini SoC

This example is bundled under the CDC-VP repository as an isolated tutorial
directory.  It is added to the existing build graph through CMake injection;
the existing CDC-VP component and platform sources are not modified.

The full write-up is `Huong_Dan_Virtual_Prototype_SystemC_TLM_v2.docx`,
generated by `docs/generate_docx.py` in the workspace next to this repository.

## Contents

- `edu_timer_tlm`: 32-bit LT target with registers, byte enables, annotated
  latency, `transport_dbg`, explicit DMI refusal, reset and a level IRQ.
  The countdown runs on an absolute tick deadline, so a register access in
  the middle of a period cannot be mistaken for a tick expiry.
- `test_edu_timer_tlm`: standalone initiator/target unit test, 27 checks
  (53 `[PASS]` lines including the per-transaction response checks).
- `mini_soc_edu_timer`: Bremen RV32 ISS + bus router + RAM + UART + timer.
- `edu_timer_demo.elf`: bare-metal C firmware executed by the RV32 ISS.
- `tests/run_regression.sh`: unit plus firmware end-to-end checks, with a
  timeout guard so a hung model fails instead of blocking CI.

## Environment

Every command below is written against these variables, so nothing carries a
personal directory layout.  Adjust the four paths to your machine -- the
`/opt` values are the install locations this example was verified against,
not a requirement.

```bash
export CDC_VP_ROOT="$HOME/work/CDC-VP"
export SYSTEMC_HOME=/opt/systemc-2.3.4
export RISCV_TOOLCHAIN=/opt/toolchains/xpack-riscv-none-elf-gcc-15.2.0-1
export VP_BUILD_DIR="$HOME/work/build-vp-tutorial"

# Derived; used verbatim by the run and debug commands below.
export FW_DIR="$CDC_VP_ROOT/vp_timer_tutorial/firmware/edu_timer_demo"
export FW_ELF="$FW_DIR/edu_timer_demo.elf"
export VP_BIN="$VP_BUILD_DIR/vp_timer_tutorial/mini_soc_edu_timer"
```

`VP_BUILD_DIR` may live anywhere; keeping it outside the repository avoids
mixing build artefacts into a working tree.

The compiler is deliberately not pinned here.  Choosing one is a per-machine
concern, and a path such as `/usr/bin/g++` fixes a location rather than a
version.  If your machine has several toolchains, set `CC`/`CXX` *before*
the `cmake` configure step -- afterwards the choice is recorded in
`CMakeCache.txt` and changing the environment has no effect.  Verified with
GCC 11.5.0 and CMake 3.21.

## Build

```bash
cd "$CDC_VP_ROOT"

cmake -S . \
      -B "$VP_BUILD_DIR" \
      -DCMAKE_BUILD_TYPE=Debug \
      -DCMAKE_PROJECT_INCLUDE="$CDC_VP_ROOT/vp_timer_tutorial/cmake/inject_tutorial.cmake" \
      -DCDC_BUILD_MINI_TLM=OFF \
      -DCDC_BUILD_CPU_EVAL=ON \
      -DCDC_BUILD_CUSTOM_SOC=OFF \
      -DCDC_BUILD_NOC_SOC=OFF \
      -DCDC_BUILD_TESTS=OFF \
      -DCDC_BUILD_TPU_V3_SOC=OFF

cmake --build "$VP_BUILD_DIR" \
      --target test_edu_timer_tlm mini_soc_edu_timer -j"$(nproc)"

make -C "$FW_DIR" CROSS="$RISCV_TOOLCHAIN/bin/riscv-none-elf-"
```

## Run

```bash
bash "$CDC_VP_ROOT/vp_timer_tutorial/tests/run_regression.sh" \
     "$VP_BUILD_DIR" "$FW_ELF"
```

Expected tail:

```
100% tests passed, 0 tests failed out of 1
FW: ID PASS / FW: RW PASS / FW: IRQ PASS / FW: ALL PASS
SIM: retired=47152
SIM: completed 1000 us
REGRESSION: ALL PASS
```

`VP_TIMEOUT` (default 300 s) overrides the regression timeout.

## Platform options

| Option | Default | Meaning |
| --- | --- | --- |
| `--fw <path>` | required | ELF loaded into RAM through the debug path |
| `--sim-us N` | 1000 | Bounded simulation time |
| `--quantum-ns N` | 1000 | Global quantum; must be >= 10 ns (Bremen cycle time) |
| `--vcd <file>` | off | VCD of `timer_irq`, `timer_reset_n`, `uart_irq`, `uart_tx` |

## Debugging

```bash
# Instruction trace from the Bremen ISS (~2.3 MB for a 1000 us run,
# so shrink --sim-us first).
CDC_ISS_TRACE=1 "$VP_BIN" --fw "$FW_ELF" --sim-us 5

# Waveform of the platform.  The demo firmware arms the timer one-shot,
# so this produces exactly one IRQ.
"$VP_BIN" --fw "$FW_ELF" --sim-us 1000 --vcd timer_debug

# Waveform of the unit test, which runs three periodic cycles and is
# therefore the right place to check IRQ spacing (rise at 149/209/269 ns).
EDU_TIMER_VCD=edu_timer "$VP_BUILD_DIR/vp_timer_tutorial/test_edu_timer_tlm"

# The VCD tracer samples once per simulation time, so a signal that rises
# and falls inside one timestamp leaves no trace.  Delta-cycle mode shows
# those pulses, at the cost of shifting the time axis by one unit per delta.
EDU_TIMER_VCD=edu_timer EDU_TIMER_VCD_DELTA=1 \
  "$VP_BUILD_DIR/vp_timer_tutorial/test_edu_timer_tlm"
```

For model-level debugging, a `Debug` build plus
`break tutorial::edu_timer_tlm::access` covers most bring-up questions; use
`break sc_core::sc_report_handler::report` to stop at the source of an
elaboration error instead of only seeing its message on stdout.
