## 4. Points to settle before redistribution

1. **YOLOv8m.** The data package contains weights derived from an AGPL-3.0 model. Internal evaluation does not
   distribute them; distributing the data package, or a product containing these weights, requires either meeting
   the AGPL-3.0 terms or holding an Ultralytics Enterprise Licence. Replacing YOLOv8m by a network with a permissive
   licence needs only a rerun of the frontend; the model source code does not depend on the network.
2. **SAURIA.** The Solderpad licence requires keeping the copyright and licence notices and stating changes when the
   ported files are redistributed. Only `tb_utilization_optimization.cpp` carries the original header today; the
   ported `rtl_ref_*` and driver files should receive the notice before any redistribution outside the organization.
3. **Images.** The input image embedded in each program is a COCO image. For material that is published, use an
   image whose licence allows it, or regenerate the program with an own image
   (`docs/VERIFICATION_REPORT.md`, section 10, V22).
