# 7. Full-Graph Model Verification Proof (100.0% Pass Rate)

The primary milestone sign-off criterion for the SAURIA FX1 SystemC virtual prototype was establishing complete numerical accuracy across full-scale production neural networks. To achieve sign-off, the virtual prototype executed full-graph ONNX models, comparing hardware output tensors against golden software reference payloads (`golden_ref.bin`) generated by `tools/onnx_compiler.py`.

Verification accuracy was evaluated using three quantitative error metrics: Maximum Absolute Error ($\text{MAE}$), Root Mean Square Error ($\text{RMSE}$), and Cosine Similarity. A layer checkpoint is designated as **PASS** only if it satisfies $\text{MAE} \le 0.000000$ and $\text{Cosine Similarity} \ge 0.999000$.

The SAURIA FX1 virtual prototype achieved a **100.0% Bit-Exact Verification Pass Rate** across both benchmark deep learning models.
