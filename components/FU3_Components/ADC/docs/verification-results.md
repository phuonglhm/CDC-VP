# Verification results - October 19, 2026

Environment: Linux through WSL, GCC 15.2.0, CMake/CTest 4.2.3 and
SystemC 2.3.4 at `/opt/systemc-2.3.4`. The source HDS is pinned in the
[README](../README.md).

| Build | Result | Scope |
| --- | --- | --- |
| Standalone Debug + gcov + Werror | 27/27 PASS | 19 direct scenarios, 7 FU3 bus scenarios and 1 executable demo |
| Standalone Release + Werror | 27/27 PASS | Checks remain active with NDEBUG |
| Standalone Debug + UBSan + Werror | 27/27 PASS | No UBSan diagnostics; sanitizer errors stop execution immediately |

The delivery uses a standalone build within the ADC directory. It is not
connected to the root build and does not modify other IP files.
CPU/SoC boot has not been verified.

Coverage for `src/adc.cpp`: 130/130 executable lines (100%); all branch
locations were executed, with 133/172 branch outcomes taken at least once
(77.33%). These are gcov/GCC measurements, including compiler-generated
branches; they are not FSM coverage or the percentage of completed HDS
requirements. SystemC/STL headers are excluded from these implementation figures.

The polling demo completed with samples `1000, 1100, 1200, 1300` and average `1150`.
The regression covers all 16 channels, 32 sample-count encodings, timing values
0/min-1/min/min+1/255, boundary and fractional averages, 160 pseudorandom
sequences, reset/disable in all 7 enabled states, missing/early/late/held-high
EOC, clock pause, malformed TLM, debug, concurrent calls, reset during
transactions and bursts through the FU3 bus.

Artifacts are regenerated by `scripts/run_full.sh` under `build/`, as described
in [testing.md](testing.md). `verification-report.json` retains `hds_signoff: false`:
BUSY/READY bit mapping, rounding, clamp readback, EOC edge/level behavior and
some lifecycle semantics still require confirmation. RTL, analog and CDC
comparisons have not been performed.
