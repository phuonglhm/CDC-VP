# Fabric and production-IP validation

The 2026-10-20 upgrade closes the three reproduced fabric integration defects
from the earlier audit and adds a coordinated reset path. The source basis
remains FU3 HAS v2.0, the supplied IP specifications and the explicit decisions
recorded in [MODEL_CONTRACT.md](MODEL_CONTRACT.md).

## Focused coverage

| Scenario | Independent checks |
|---|---|
| Safety regression | Preserved FIXED at the last word on both SYSBUS paths; repeating enables and final memory bytes; invalid INCR has no target effect; protected words on both PERIBUS paths; rejection before earlier CSR effects; quiescence includes annotated delay and releases after target exceptions. |
| Native DMA adapter | Native sparse lane strobes AND existing enables; multi-beat byte FIXED; metadata conflicts, missing metadata and malformed beats; downstream errors stop remaining beats; native fault/response observations survive; temporary fields restored after exceptions. |
| Production DMA data flow | Unaligned 63-byte M2M copy against a generated byte pattern; eight-word SPI0 loopback and eight-byte UART2 loopback through real DMA with request/clear acknowledgments and FIFO/error checks. |
| Timer and PLIC | A real Timer1 interrupt pulse reaches the real PLIC; rejected narrow/partial/all-disabled claim reads preserve pending IRQ; aligned word claims source 6 once and completes it; ordinary narrow configuration access still works. |
| WDT and reset | Existing WDT0 requests reset while CPU/DMA work is pending; ingress closes and admitted work drains; platform resets IP models and reopens staging; DMA successfully transfers again after reset. |
| Installed use and coexistence | Installed static/shared bus packages run all four paths and the safety suite; FX1 and FU3 link in one executable with `sc_main`. |

The production fixture is [real_ip_tests.cpp](../tests/ip_integration/real_ip_tests.cpp).
DMA, SPI, UART, Timer, WDT and PLIC are actual component models. SRAM peers are
sparse test memories. CPU request generators, reset orchestration and the DMA
request mux are fixture code. Request selector bits 1..4 connect SPI TX/RX and
UART TX/RX; they are fixture assignments, not newly specified FU3 mux encodings.
The fixture uses both A2P/PERIBUS paths. It does not replace tests for every IP
instance, mode or architectural source assignment.

## Reproduction

Run the static/shared, installation and coexistence commands in the
[README](../README.md#build-and-test), adding
`-DFU3_BUS_BUILD_IP_TESTS=ON` to both bus configurations. The optional integration
tests require the sibling production-IP directories. Installed consumers require
only the exported bus package and compatible SystemC.

## Interpretation and remaining work

The supported conclusion is functional fabric behavior plus exercised production
DMA/peripheral/IRQ/reset interoperability. These tests do not demonstrate CPU
instruction execution or full firmware boot, complete system security, exact AXI
channel timing, or physical pin/RTL behavior. A target that never returns still
needs a platform fault/recovery policy; quiescence deliberately adds no guessed
timeout or cancellation semantics. Debug loaders must be stopped separately.

WDT integration uses the existing V1.1 component contract. Migration to the
supplied WDT V1.2 is separate work and is not implied by this bus validation.
The compact PLIC claim/complete map and other provisional endpoint contracts
remain subject to their IP-owner decisions.
