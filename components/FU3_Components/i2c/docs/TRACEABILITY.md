## Coverage boundaries

No CPU firmware binary is executed. IRQ fan-out uses fake sinks rather than a PLIC register model. There is no DMA path, matching the architecture assignment. Pad electrical properties, full multi-master clock synchronization, speed-mode certification, exact legacy filter timing, and runtime CRM clock changes are not qualified. The legacy filter formula remains a documented VP approximation.

The collision regression is direct-socket only so its MMIO boundary is controlled independently of fabric latency. The integration suite repeats functional serial tests through the real bus; it does not assume a specific end-to-end MMIO cycle count.

Further verification can expand partial-byte repeated START/STOP cases, malformed transport/debug requests, and simultaneous multi-master stress. Passing the current suite is not evidence of exhaustive protocol compliance.
