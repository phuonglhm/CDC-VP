# FX1 ISP VP — acceptance evidence

These are the records the standalone acceptance (M4, M5) rests on. Large
artefacts (NV12, previews, per-run manifests, about 620 MB) are not in the
repository: they are regenerated by the commands below and verified against
the checksums kept here.

**Evidence level:** every result is an agreement between the C++ model and
the project's own Python reference. There is no owner golden or RTL
(DEC-05).

| File | Content | Produced by |
|---|---|---|
| [raw_regression_baseline.json](raw_regression_baseline.json) | SHA-256 of the NV12 of **every frame** (308) and of the statistics readout after the last frame, for all 116 runs: 28 RAW × 4 presets in their own sessions, plus the 28-frame back-to-back sequence for each preset. No host paths or timings. | `tools/run_regression.py --write-baseline` |
| [raw_regression_baseline.md](raw_regression_baseline.md) | The same as tables. | same |
| [ctest_summary.txt](ctest_summary.txt) | Final CTest run: every test, including the real-RAW regression compared with the baseline. | `ctest` with `-DFX1_ISP_CSR_XLSX` and `-DFX1_ISP_RAW_INVENTORY` |
| [mutation_summary.md](mutation_summary.md) | Mutation checks of statistics, continuous operation, block status and the reference driver. | scratch harness (M3-R6) |
| [environment.txt](environment.txt) | Host, compilers, CMake, SystemC, Python, git state. | — |

Committed elsewhere in the tree, and checked by CTest:
- `tests/data/4k/*/expected_nv12.sha256`: 4K NV12 checksums;
- `tests/data/vectors/`, `tests/data/blocks/`, `tests/data/sequences/cont_100/`:
  vectors with full expected data;
- `docs/ISP_CSR_TRACEABILITY.md`: per-register coverage gate.

## Where the evidence can be re-run

| With | What can be re-run |
|---|---|
| The install prefix only (`share/doc/fx1_isp/evidence`, `share/fx1_isp`) | The 4K bit-exact check, with no Python and no dataset: `share/fx1_isp/samples/run_4k_check.sh`. With Python, numpy and the dataset: the real-RAW regression against this baseline, using `share/fx1_isp/tools/run_regression.py --run-raw bin/fx1_isp_run_raw --baseline share/doc/fx1_isp/evidence/raw_regression_baseline.json`. |
| The source checkout (required for the full evidence) | Every CTest test: unit and integration tests, vectors, G-CONT, driver, package, traceability gate, generator checks. The tests, vectors and generators are not installed. |

## Reproduce and verify

```bash
export CC=/usr/bin/gcc CXX=/usr/bin/g++ PATH=/usr/bin:/bin:$PATH
cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=$CXX \
      -DFX1_ISP_CSR_XLSX=<doc>/FTEL_IP_ISP_CSR_v1.0.xlsx \
      -DFX1_ISP_RAW_INVENTORY=<plan>/ISP_RAW_INVENTORY.json -DFX1_ISP_RAW_OUT=<out>
cmake --build build && ctest --test-dir build
```

`fx1_isp.regression.raw` fails if any frame or statistics checksum differs
from `raw_regression_baseline.json`. An intended model change must
regenerate the baseline, together with a decisions-log entry explaining why
the outputs changed:

```bash
python3 tools/run_regression.py --inventory <plan>/ISP_RAW_INVENTORY.json \
        --run-raw build/fx1_isp_run_raw --out <out> --jobs 8 \
        --write-baseline docs/evidence/raw_regression_baseline.json
```

The baseline was generated after the M5 changes (DEC-38/39, M5-A1). Its 308
frame checksums are identical to those of the M4 run the reviewer approved:
the M5 changes touch status bits and warnings, not pixels.
